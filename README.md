# Real Estate Market Analysis | Power BI

## Project Overview
This project analyzes real estate market data using Microsoft Power BI to explore property prices, geographic differences, and market trends.

## Dashboard Pages

### 1. Real Estate Market Overview
- Key performance indicators for property records and prices.
- Average purchase price by city and property type.
- Property price trends over time.
- Relationship between property size and purchase price.

### 2. Geographic & Market Insights
- Geographic visualization of real estate data.
- Average price per square meter across cities.
- Inflation and interest rate trends.
- Comparison of property transactions by sales type.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Exploratory Data Analysis

## Key Objectives
- Explore real estate price patterns.
- Compare property prices across locations.
- Examine trends in economic indicators.
- Present findings through an interactive dashboard.
